万能文件转换器 v0.3.0（Windows 便携版）
==================================================

使用方法
v0.3.0 更新：
- 每行可单独选择格式；选择“跟随批量设置”可恢复顶部控制。
- 完成后可打开或定位结果；失败可查看原因。
- 转换结果先写临时目录，检查文件非空后发布，失败不会覆盖旧文件。
- 多文件输出保存在独立的 _pages 文件夹；同名文件夹自动编号。
- 安装与转换互斥；任务结束后才能关闭程序。
- 转换页和引擎页都可导出诊断日志（含本机路径，请确认后再分享）。
- 安装区分成功、没有适用更新及失败，保留退出代码。
首次打开会显示引擎检查报告，可前往安装、重新检测或跳过。
勾选“不再自动弹出”仅关闭报告弹窗，后续启动仍后台检测。
旧版升级至本版后会展示一次此引导；不会自动安装软件。
本版修复 winget 应用别名检测、PATH 未刷新时的查找，并在安装日志记录检测结果。
同时修复已就绪引擎被误判为缺失的问题。
--------------------------------------------------
1. 请先完整解压整个 ZIP。
2. 双击“万能文件转换器.exe”。
3. 第一次打开后进入“转换引擎”页面，点击“安装常用引擎”。
   软件会请求管理员权限，并在管理员 CMD 中更新软件源、升级或安装最新版。
4. 把文件或文件夹拖进窗口，选择目标格式并开始转换。

智能推荐一定会选择不同于源文件的常见格式。队列中的长文件名可通过
表格底部的横向滚动条完整查看。

本版本不需要安装 Python，也不需要运行任何 BAT。

重要说明
--------------------------------------------------
- EXE 旁边的 resources、locales、*.dll 等文件是程序运行所必需的，请勿单独移动 EXE。
- 软件本身不上传文件；所有文件都在本机转换。
- 默认同名时自动重命名，不会覆盖原文件。
- 请正常双击启动，不要使用“以管理员身份运行”；Windows 会阻止资源管理器
  向管理员权限窗口拖放文件。
- 队列中的“缺少引擎 →”可以点击，会自动跳转并定位到需要安装的引擎。
- 如果 Windows SmartScreen 提示“Windows 已保护你的电脑”，这是因为个人制作的
  程序没有购买商业代码签名证书。可点击“更多信息”→“仍要运行”。
- 转换引擎由 winget 安装。Windows 11 通常已自带 winget。

支持类型
--------------------------------------------------
视频/音频：FFmpeg
图片/HEIC/PDF 页面：ImageMagick + Ghostscript
Word/Excel/PPT：LibreOffice
Markdown/HTML/LaTeX：Pandoc
电子书：Calibre
压缩包：7-Zip

便携引擎
--------------------------------------------------
如果不想安装到系统，也可以把免安装版引擎放进 EXE 同目录的 tools 文件夹，
程序会自动搜索其中的 ffmpeg.exe、magick.exe、soffice.exe、pandoc.exe、
ebook-convert.exe、7z.exe 和 gswin64c.exe。

故障排查
--------------------------------------------------
程序启动错误会写入：
%APPDATA%\universal-converter-cn\运行错误.log

转换失败时，请打开界面右下角“运行日志”查看 Error 和 Debug 信息。
